# Product-oriented cover images

Current covers use restrained interface illustrations explaining each project's actual purpose. Created with the built-in image_gen tool, then encoded as WebP for the site. They are illustrative presentations; actual application captures remain in case-study galleries. No image-generation captions appear in the public UI.

Saved assets: `public/projects/art/findurway-product.webp`, `lms-product.webp`, `darija-product.webp`, `rag-product.webp`.

## findurway

Create a professional portfolio cover image for the software project "FindUrWay". Landscape 3:2, 1536x1024 style composition. A polished job-matching web application shown straight-on. A narrow left panel titled 'Your skills' with chips Python, SQL, React. A main panel titled 'Find your next role' with three clear job cards: 'AI Engineer', 'Data Engineer', 'Software Developer'. Each card shows matching skill chips and a small bookmark icon. A simple search field at top. A visible profile-to-role relationship through understated highlighted matching chips. Ivory UI, deep forest-green navigation, muted lime highlights. The product interface fills about 85% of the frame, on a plain lightly textured background with a natural shallow shadow and generous outer margin. Design it like a meticulous human product designer's presentation: believable spacing, crisp readable typography, realistic interface controls, minimal copy. Make the project purpose immediately recognizable. No surreal art, no sculptures, no glowing orbs, no neon, no chrome, no glass ribbons, no fake statistics or percentages, no customer counts, no AI symbols, no watermark, no labels about image generation. No laptop bezel. This is an illustrative product presentation, not a claim of a real screenshot.
